# v0.86：検索中心のトップページ

トップページからアーティスト名と個別作品数のボタン一覧を撤去し、簡潔な説明・検索欄・全体の登録作品数を表示する。全体数は同梱目次の公式確認済みとして表示可能な作品から計算する。199を固定表示しない。検索後も全体数を保ち、検索状態欄にアーティスト名とその登録作品数を表示する。

既存の色・書体を基に上部の余白を調整し、説明15px、補足・全体数14px、検索入力16pxと44px以上の操作領域を維持する。アーティスト追加に伴うトップページの縦方向の伸長を抑える。リストを開く代替UIや新しい設定は追加しない。

作品名・アーティスト・発売年・発売元・YouTube Musicリンクは従来どおり表示。公式発売の根拠URL、資料確認日、確認済み配信先の補足と代替検索は「発売情報・根拠を見る」に保持。既存14組199作品・全6直接リンク・検索URL生成・ローカル保存・バックアップ復元処理は変更しない。データファイルの差分はゼロ。

目次取得失敗時には全体数を0と表示せず、読込失敗を明示し再試行で復帰する。未対応アーティストの検索結果と全体登録数を混同しない。将来用の任意APIモードでは静的目次の読込待ち表示を隠し、既存のAPI経路を維持する。

回帰検証は320/390/430px、14組の日英検索、199作品の主要項目・リンク・根拠開閉、アーティスト別件数、総数保持、取得失敗と再試行、保存記録保持を対象とする。さらに200組増やしたテスト用目次で、検索欄が初期画面内にあり、一覧が復活せず、総数のみ更新され、横にはみ出さないことを確認する。

GitHub Pagesのみ。API・DB・外部サービス・画像・依存関係の追加なし。iPhone実機Safariと公開反映は自動テストとは別に確認が必要。
