# RECORD v0.68: grouped work list

## Behavior

The default list shows one edition card per MusicBrainz release-group ID. Additional editions are inside a native, keyboard/touch-accessible disclosure labeled 「ほかの発売盤を見る」. The displayed card is the first retrieved edition, not an assertion that it is the original, recommended or independently verified edition. The setting panel explains this choice.

Different work IDs with the same title remain separate. Missing work IDs use the release ID as their key. Only identical release IDs are deduplicated. Every edition keeps its label, date, tracks, credit evidence, official-reference evidence, source and saved YouTube Music link. No evidence or label is inherited from another edition.

The disclosure's open state survives re-render. Existing edition nodes are moved rather than recreated during incremental loading, preserving URL drafts, focus, open detail and track state. Newly fetched editions join their own work's disclosure. Existing chronological loading, alias search, request cache, artist scopes and backup format are retained.

## Validation

Local: Python matching 32 tests, all five Node suites and diff whitespace checks pass. Browser tests run in PR CI because local Chromium download is unavailable. New UI regression covers 320/390/430px, three editions of one work, a different work with the same title, two records without work IDs, disclosure opening/closing, late edition insertion, draft/focus/node preservation and per-edition label/date isolation. Existing Norah official-reference test now opens the containing work disclosure before inspecting its reissue; the image-failure test does the same for its second edition.

Previously captured real Norah Jones, Miles Davis and Jeff Beck fixtures remain part of CI. This is offline replay, not fresh external MusicBrainz or YouTube Music verification. No iPhone Safari or actual playback verification is claimed.

## Limits

The first edition may have incomplete label information; alternatives are available in its disclosure. Works still wait for the current chronological range and release page to load. This change reduces repeated visible cards, not initial external API latency. A work's edition count means retrieved editions in the selected scope, not all editions ever released. v0.68 is submitted as a PR; publication requires merge authorization.
