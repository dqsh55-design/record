# RECORD v0.71: independent work evidence across artists

## Changes

Four reviewed work references supplement the existing six references: Miles Davis, Kind of Blue (studio, 1959); Jeff Beck / Jan Hammer Group, the joint live work (1977); Jeff Beck, Beckology (compilation, 1991); The Jeff Healey Band, See the Light (studio, 1988). This extends coverage to four artist identities including Norah Jones, not four complete catalogs. No new edition-level independent confirmation is added. The existing independently matched Norah reissue remains.

Official references:

- https://www.milesdavis.com/albums/kind-of-blue/ — release date, Columbia label and discussion of the studio sessions. No original label is copied onto later editions.
- https://www.sonymusic.co.jp/artist/JeffBeck/profile/ — explicit 1977 live entry with Jan Hammer Group and 1991 three-disc best-of entry.
- https://jeffhealey.com/album/see-the-light/ — band credit, 1988, Arista and studio recording location. Neither exact day nor catalog number is independently established by this page.

Reviewed facts and scope are in `docs/v0.71/reviewed-sources.json`; factual paraphrases only. The Miles/Beck MB fields come from previously saved real API responses in v0.64. The new Healey fields are a minimal manual transcription of visible MusicBrainz release/artist pages in `healey-web-fields.json`, explicitly not an API snapshot. The work ID was observed in the release page's work link; the artist index supplied the work year and credit. The work page itself displayed a browser verification wall, which was not bypassed. A normal direct API attempt returned non-JSON and was not accepted as evidence.

The main card now shows a short work-confirmed or conflicting badge, with an explicit reminder that individual editions require separate checks. Unknown work evidence stays in details. Late reference arrival and track-detail updates refresh the badge without replacing the card or input. Japanese aliases for Jeff Healey and his band are separate search terms; their artist IDs are not merged.

Edition matching now requires label and catalog number to coincide in the same label-info entry. It cannot combine label A from one entry with catalog X from another. Positive track counts and meaningful formats are required; null/zero/unknown specifications cannot confirm. Source URLs must parse as HTTPS URLs without embedded credentials, and label/publisher placeholders cannot serve as meaningful evidence. Explicit negative work facts produce conflict rather than confirmation. Missing or contradictory facts never promote an edition or streaming link.

## Validation

Local Python matching 32 cases, Node six suites, Python syntax and diff checks pass. Extended classification tests cover the four new work references, same-name/different-ID and year conflicts, positive/negative work conflicts, label/catalog entry mixing, invalid sources, placeholders and unknown media. Existing Norah studio/live/compilation/reissue cases still pass.

The new browser case at 320/390/430px verifies Miles studio, Beck joint live and compilation, and Healey Band studio work badges, source links, edition-unconfirmed text, year-conflict refresh, no direct-listening promotion and no horizontal overflow. The Beck compilation edition is explicitly synthetic UI input containing a real captured work index; it is not release evidence. Existing draft, grouping, chronology, loading, alias and backup tests remain in CI.

## Limits

This is a manually reviewed, small reference set, not automatic official-site discovery or complete discography certification. Public web page retrieval and old-response replay are distinct from a fresh successful API audit. Only the reviewed works gain work-level confirmation; all other editions still depend on their own evidence. YouTube Music rights/playback, actual image delivery and iPhone Safari remain unverified. v0.71 is submitted as a PR without publishing.
