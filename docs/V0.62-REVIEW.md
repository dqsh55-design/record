# RECORD v0.62 実装・検証記録

2026-10-26（日本時間）。v0.61がマージされた最新mainを基点とする新規PR。今回のマージ・公開反映は行わない。

## 直接リンクの判定

MusicBrainzを発売記録の情報源として維持。既存の照合パイプラインに発売年を追加し、新規の自動照合根拠をversion 2として生成する。

- 同じ発売盤のアーティスト、タイトル、発売年、レーベル、曲数、曲名、曲順、公式発売登録の全項目が一致した場合のみsupported。
- 年の欠落は情報不足、年の相違は不一致として検索に戻す。配信盤が初出年を名乗り、発売盤が再発年の場合も推測して一致にしない。
- 自動照合に渡せるIDはアルバム専用の`MPREb_...`だけ。プレイリスト・動画IDは外部APIを呼ぶ前に拒否。
- 一覧の直接リンクでは、30日以内、選択したアーティスト名、対象発売盤ID、全照合項目、現在のタイトル・発売年を確認する。URL・アルバムID・YouTube側の出典URLも同じアルバムに結び付く必要がある。
- 条件を満たした場合は「YouTube Musicで聴く」、満たさない場合は「YouTube Musicで探す」。現在の再生可否と配信許諾は確認したと表現しない。
- `data/ytmusic-albums.json`に保存された根拠を使用し、ブラウザから制限を回避してYouTubeを探索しない。既存の`verify_catalog.py`で再照合するとversion 2の根拠を生成できる。
- 旧version 1の根拠は従来の詳細表示に残し、発売年の根拠を補わずに新しい「聴く」リンクへ昇格させない。

## 一覧デザイン

ジャケットはデスクトップ128px、スマートフォン96px、320px幅では84px。遅延読み込み、HTTPキャッシュ、画像なし表示と失敗キャッシュは維持する。曲名は17〜19px、発売年・盤種・国・仕様・曲数、レーベルを整理して表示する。

発売盤ID、バーコード、詳細な発売日、規格品番、出典リンク、照合根拠は折り畳み詳細へ移動。年は作品の初出年ではなく、その発売盤の登録年。再発・国別盤をIDで保持し、誤って統合しない。バックアップ操作は一覧の後ろに配置する。

## 保存・バックアップ互換性

既存localStorageのキーと`RECORD-verification-v1`形式を変更しない。既存の作品単位リンク、照合記録、発売盤別リンクを維持する。利用者が保存したURLは「利用者登録・未照合」として詳細から開けるが、自動照合済みのリンクへは昇格させない。

旧バックアップにあるアルバム用OLAKプレイリストURLも削除せず復元し、未照合の保存リンクとして保持する。新規の発売盤リンク保存にはアルバム専用browse URLを要求する。動画URLを受け入れない。手入力されたURLを正規配信確認済みとは表示しない。

## 実接続（模擬テストと区別）

[実接続レポート](v0.62/live-report.json)を参照。

- Jeff Beck：MusicBrainz HTTP 200。発売記録253件中100件、うち公式Album 79件。Flashの発売盤詳細もHTTP 200。
- Miles Davis：MusicBrainz HTTP 200。発売記録1972件中100件、うち公式Album 55件。Milestonesの発売盤詳細もHTTP 200。
- 全ページの検査ではない。今回の詳細レスポンスを`v0.62/*-edition.json`に保存。発売盤一覧のオフライン再生には既存v0.61のスナップショットも使用する。
- 両者のCAAサムネイルはHTTP 307でarchive.orgへ転送。この環境の許可リスト外なので追わず、実画像の受信成功は未確認。
- YouTube Musicへの通常接続はプロキシCONNECT 403。YouTube側のHTTP応答は未確認。拒否後の再試行や別経路・認証回避をせず、2人目の接続は省略。
- 実接続から新しい確認済み直接リンクを生成していない。接続確認用スクリプトは`python scripts/validate_v062_live.py`（requestsが必要）。通常のテストからは実行しない。

## 自動・ブラウザテスト

- `python -m unittest discover -s tests -p 'test_*.py' -v`：53件成功（照合32件、Chromium画面21件）。
- `node tests/test_browser.cjs`：成功。URLと根拠の結び付き、別年・別アーティスト・別URL・期限切れ、プレイリスト・動画URLの除外、保存失敗時のロールバック等。
- Python構文チェック、`git diff --check`も実施。
- 画面テストはAPIを模擬する。320 / 375 / 390 / 430px、タッチ操作、横はみ出し、主要操作44px以上、画像成功・404、曲順、既存検索、保存・再読込・削除・バックアップ復元を確認。
- FlashとMilestonesの実取得MusicBrainz詳細を再生し、対応する**模擬YouTubeメタデータ**をテスト内だけで生成。照合生成→一覧表示→「聴く」→曲順→プレイリストURLに変わった場合の検索への切替を検証。これらは実際のYouTubeアルバムURLの確認ではなく、模擬統合テスト。架空URLを本番カタログへ保存していない。
- 同名・同年のModern Jazz Trumpetsの別ID・8曲/9曲を維持する既存テストも通過。

## 残る確認

CAA実画像の表示、iPhone実機Safariでの見た目・速度・キャッシュ、実際のYouTube Musicアルバム情報の取得と照合は接続可能な環境で確認が必要。Chromiumのスマートフォン模擬画面をiPhone実機検証とは扱わない。

発売年が未登録の盤や、配信年と再発年が異なる盤は保守的に検索リンクとなる。これは根拠を推測して別盤へ誘導することを避けるための制約。
