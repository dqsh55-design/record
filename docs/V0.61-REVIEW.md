# RECORD v0.61 実装・検証記録

検証日：2026-10-26（日本時間）。公開・マージは行わない。

## 変更

- MusicBrainz-firstを維持。発売盤IDのCAA `release/{id}/front-250`で76px（小画面66px）のジャケットを表示。
- `loading=lazy`、非同期デコード、低優先度、サイズ予約、ブラウザHTTPキャッシュを利用。画像バイナリはlocalStorageに保存しない。
- CAAに表ジャケットがないと登録されている盤は取得を省略。取得失敗時は「画像なし」。失敗をメモリ上で5分、最大500件記憶し、再描画による失敗リクエストの反復を抑制。画像取得はMusicBrainz検索・曲目取得のキューを使用しない。
- 直接リンクは、本人名義、アルバムID、有効期限30日、supportedの判定、その発売盤IDのsupported候補がそろう既存自動照合データに限る。根拠の日時・発売盤ID・レーベル・曲目を表示。根拠がない場合は検索リンクを維持。
- 利用者が発売盤ごとにURLを保存・削除可能。HTTPSのYouTube MusicアルバムURLのみを許可し、共有パラメータを除去。利用者登録は照合済み判定に昇格させない。検索リンクも残す。
- `recordEditionLinksV1`に保存。保存失敗時はメモリ上の記録も更新しない。既存の作品単位の保存記録には触れない。
- 既存の`RECORD-verification-v1`バックアップに省略可能な`editionLinks`を追加。旧ファイルも読み込める。新しい記録を優先して統合。発売盤リンクのみのバックアップも復元可能。
- 取得時と描画時に同一発売盤IDを除外。重なる再検索では古い応答を破棄。異なるIDは統合せず、国・品番・盤仕様・曲数・注記・バーコード・完全な発売盤IDを表示（登録がある項目のみ）。
- 既存のYouTube Music実接続診断を明示的なCLI実行に限定し、unittestのテスト探索時に外部アクセスしないよう変更。

| --- | --- | --- |
| `6fbb6d1b-e6b4-4027-acf1-85045a0bd771` | 1951 / US / Prestige / PRLP 113 / 10インチ盤 | 8曲。Dynamo、About Midnight、Diggin’ Dizzy等 |
| `f5453a0d-414c-4974-b26f-9ceea9b35887` | 1951 / US / Prestige / PRLP 113 / 10インチ盤 | 9曲。Stop、Go、Wailing Wall、Morpheus等 |

同一IDの二重取得ではない。登録曲目が異なるため、タイトル・年・レーベル・品番だけで統合しない。実物の別仕様なのかMusicBrainzの誤登録なのかは未確定であり、実物の別仕様と断定しない。出典リンクと曲目で利用者が比較できる。元データの修正・統合は行っていない。

## 実接続テスト

`docs/v0.61/live-report.json`と同ディレクトリのレスポンスを参照。

- Jeff Beck：発売記録253件中、先頭100件を実取得。IDは100件すべて一意。
- Miles Davis：発売記録1972件中、先頭100件を実取得。IDは100件すべて一意。
- Modern Jazz Trumpets：検索結果2件と、それぞれの発売盤詳細をHTTP 200で取得。全アーティストの全ページを検査したわけではない。
- `inc=media`を含む通常のMusicBrainz APIで盤仕様と曲数の取得を確認。一時的な503は間隔を空けた最大3回の再試行で取得できた。
- CAA：Flashのメタデータとfront-250はHTTP 307でarchive.orgへ転送。転送先は環境の許可リスト外で、初回の通常アクセスはプロキシ403となった。以後は転送を追わず応答のみ記録。**ジャケット画像の実配信成功は未確認**。
- YouTube Music：通常接続はプロキシのCONNECT 403で失敗。YouTube側のHTTP応答は確認できていない。回避・別経路・認証迂回は行わず、実データで新しい直接リンクを確認済みにしていない。

`python scripts/validate_v061_live.py`は実接続用の明示的診断（requestsが必要）。通常の自動テストからは実行しない。

## 残る課題

- CAAの実画像表示はarchive.orgへ接続できる通常ブラウザで確認が必要。iPhone実機Safariでの速度・キャッシュ挙動も未計測。
- YouTube Musicの実接続照合は接続制限が解消されるまで保留。対応根拠のない作品は検索リンクを使用する。
- MusicBrainzの登録内容自体の正誤は保証しない。Modern Jazz Trumpetsの2件は曲目が異なる登録として維持する。
- 画像の失敗キャッシュはページ内のみ。再読込では再取得可能。利用者の保存リンクはこのブラウザ内に保存され、端末間はバックアップで移行する。
