# RECORD v0.63：年代順の発売アルバム一覧

最新のmain（v0.62、a87dece）から変更。PRの作成までを対象とし、マージ・公開反映は行わない。

## 動作

初期表示は作品の初回発売日の古い順。「新しい順」へ切り替えられる。1950年代などの見出しを表示し、初回発売年不明はどちらの順でも末尾の別区分とする。個別盤の日付から作品の年を推測しない。

MusicBrainzのrelease-groupの`first-release-date`を作品の初回発売日として使用する。共同編集データであり、初出の正規盤の年を独立に確認した値ではない。画面にもこの範囲を明記する。各盤の`date`は「この盤の発売」と別に表示する。後年の再発盤は作品の年代にまとめ、再発と断定するラベルは付けない。国別盤・正規再発・ライブ・ベストは発売盤IDごとに残し、タイトルでまとめない。非公式区分の除外と不明区分の確認待ち表示はv0.62を維持する。

年代順の途中に未取得の古い作品が割り込むことを防ぐため、最初に**軽量な作品索引だけ**を100件ずつ取得して順番を確定する。索引準備中は件数を表示し、不完全な年代順一覧を完成扱いしない。発売盤・レーベル・画像・曲目の全件先行取得は行わない。索引順に作品ごとの発売盤を最大100件ずつ取得し、その作品のページが完了してから次の作品へ進む。索引内の作品全体を取得対象とし、100件で終了しない。

画面末尾の500px手前で追加取得する。手動ボタンも残す。通信失敗時には自動追加を止め、同じoffsetから再試行する。通信中の多重実行を防ぎ、発売盤IDを重複排除する。検索対象や並び順の変更で世代を更新し、古い応答を混入させない。作品索引の取得失敗後も再開でき、空ページ・不正な件数は完了として扱わない。

追加読み込み時は既存の発売盤DOMを再利用し、画像・開いた詳細・曲目を保持する。画面外カードには`content-visibility`を適用し、画像の遅延取得・寸法確保・44px以上の操作領域を維持する。対応ブラウザ以外でも通常の縦長一覧と手動追加で利用できる。

並び順を切り替えると索引を並べ直し、その方向の先頭から発売盤を段階取得する。未取得の新しい作品が後から先頭へ割り込まない。切替後の発売盤は再取得する。主一覧は選択名義の作品索引が対象で、Jeff Beck Groupなどの別名義は既存の関連バンド導線でたどる。

YouTube Musicの検索、根拠付きの盤リンク、手動登録、保存キー、バックアップ形式は変更していない。ジャケットのフォールバック・詳細の折りたたみも維持する。
