# RECORD v0.66 — 正規発売の根拠と作品・発売盤の分離

v0.65を含むmain（`1fab66d`）を基準に変更。mainへのマージ・公開反映は行わない。読み込み速度の最適化は今回の対象外。

## 調査した経路と変更

主一覧は`index.html`の作品索引（`loadIndexPage`）→作品ごとの発売盤browse（`loadOfficialReleases`）→任意の曲目・名義詳細（`showEditionTracks`）を使う。従来は`releaseVisibility`がMusicBrainzのstatusだけを参照し、`typeOf`がLive/Compilation以外のAlbumをスタジオ盤にしていた。ID以外による発売盤の削除は行っていなかった。

- `albumKind`はAlbumの副種別を明示的に分類。Live+Compilationを両方保持し、Remix/Soundtrack/Demo等をスタジオ盤へ誤分類しない。タイトル中の「Live」「ベスト」「Bootleg」やレーベル名を正規性の根拠にしない。
- `assessRelease`はMBのOfficial登録、作品の公式資料照合、発売盤の公式商品情報照合を分離。未確認は海賊版と判定しない。明示的なMB Bootleg/Pseudo-Release/Promotion登録は従来どおり除外するが、登録と公式商品資料が矛盾する場合は未確認として保持する。Withdrawn/Cancelled/区分欠損も確認待ち。
- 作品の根拠は作品ID・アーティストID・種別・初回発売年、発売盤の根拠は発売盤ID・作品ID・アーティストID・発売日・品番・各ディスクの曲数・規格を照合する。後者では出典の発売元またはレーベルが必要。レーベルを指定した場合はその文字列も一致が必要。作品の確認を他の発売盤へ伝播させない。
- 根拠は`data/discography-references.json`に出典URL・確認日・確認範囲・レビュー内容付きで保持する。人が公式資料を読んでIDとの対応を確認したデータであり、URL文字列から公式性を自動認定するものではない。判定コードにNorah Jonesの名前・ID・特例分岐はない。他のアーティストにも同じ形式を追加できる。
- 索引の初回発売日と各盤の発売日は分離したまま。再発の年だけで「正規再発」と推測しない。レーベル（MBのimprint）と公式商品の発売元は別欄で表示し、再発元を初回発売元に流用しない。初回発売年が公式資料と食い違う場合はカードにも未確認と表示し、年代順の基準値を黙って書き換えない。
- 同じ発売盤IDは一度だけ表示。同じ作品IDに作品見出しと取得済み発売盤数を付ける。異なる発売盤IDは削除・統合せず、同じバーコード・品番・曲数でも保持する。同名で別の作品IDも別作品。作品ID欠損時は発売盤単位を維持する。
- 任意取得した詳細のstatus・レーベルを最新の判断に使う。詳細によって初回発売日を上書きしない。公式根拠の遅着・曲目の取得でも既存カードや入力中のURLを保持する。

## 実取得の範囲

`docs/v0.66/capture.json`に要求URL・HTTP結果と確認時刻を記録。全56 Album作品の索引、指定した6作品の発売盤全ページを取得した。発売盤は82件（Official 72、区分欠損4、Withdrawn 2、Bootleg登録4）。一時的な503は間隔を守って再試行し200で完了した。全56作品の全発売盤を取得した検証ではない。

通常のHTTPS・継承したプロキシ・TLS検証を使用。初回の権限を付けない実行ではプロキシに接続できなかったが、ネットワーク権限を付けたコマンドで取得に成功した。認証や証明書の回避はしていない。公式資料はWeb検索・ページ閲覧で確認した。MusicBrainzの実応答、公式資料を読んで作成した照合データ、生成した異常系テストを区別している。
