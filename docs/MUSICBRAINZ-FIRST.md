# 発売記録を起点にする方針（v0.60）

主一覧はMusicBrainzのアーティストIDに結び付いた発売盤を100件ずつ取得する。release-groupのAlbumに属する発売盤を表示し、Studio / Live / Compilationを分類する。国別盤や再発盤をタイトルで統合しない。再発という判定を発売年だけから推測しない。

Official登録はレーベル・品番・曲目の欠損にかかわらず残す。Bootleg、Pseudo-Release、Promotionは主一覧から除外する。WithdrawnやCancelledは過去の発売実績がある可能性を断定せず、確認待ちとして残す。発売区分不明は「確認待ち」として残し、非公式とは断定しない。MusicBrainzは共同編集の記録であり、Official登録も法的な許諾の証明ではない。発売元不明という欠損だけではOfficial登録を取り消さない。

発売日・国・レーベル・品番・出典を表示する。曲目は各発売盤の詳細エンドポイントから取得し、ディスク番号と曲番号を表示する。曲目未登録と通信失敗を区別し、失敗時は再試行できる。初回は全件ではなく最初の100件であり、取得件数と残件を表示する。Jeff Beckは253件、Miles Davisは1,971件の発売記録があるため、全件取得には追加操作が必要。非アルバムの発売記録も取得件数に含まれる。

各盤にアーティスト名・作品名でYouTube Musicを検索するリンクを付ける。自動的な直接リンクの推定はしない。従来の利用者による確認済みリンクは作品単位の記録として表示し、発売盤の同一性と配信許諾は未確認と明記する。既存URL・カタログ・localStorageのキー・バックアップ形式は変更しない。従来の一覧・手動保存・照合機能は折りたたみ内に残す。

YouTube Musicカタログ取得と主一覧の取得は独立して開始し、主一覧はYouTube APIやレーベル取得の成功を待たず表示できる。旧カタログ更新・照合workflowの定期起動は停止し、手動実行は残す。旧方式のコードを新方針の前提にしない。MusicBrainz障害時はエラーと再試行を表示し、取得済みの発売盤と従来カタログを維持する。
