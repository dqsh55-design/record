# v0.75 Columbia時代の主要作品を追加

PR #19をマージし、Pages配信の成功を確認した後、Sony Music運営のマイルス公式作品ページ本文を個別に閲覧・照合して18作品を登録。マイルス8→26作品、ノラ12作品、合計38作品。各作品の公開カードから元の公式作品ページへ移動できる。

## 確認方法

作品名、本人のアルバムであること、Label=Columbia Records、Release Date、Recording Periodを区別して確認。Sony日本公式2006年復刻企画の該当タイトル・品番も補助照合した。復刻年を初回発売年として使わない。確認できない作品の追加や、MusicBrainzのOfficial登録からの昇格はしない。

通常HTTP取得はSony米国作品ページ・Sony日本の旧特設ページでも403。無効な自動取得設定を維持し、IP変更・User-Agent偽装・プロキシ・認証回避は実施していない。今回閲覧できた公式ページ本文の情報はWeb取得サービスを通したレビューであり、当環境からの直接HTTP自動収集成功ではない。検索結果の短い断片だけで認定した作品はない。自動取得可能なWarner、Blue Noteの収集処理は継続する。

レビュー記録は `data/official-reviews/miles-columbia-2026-10-27.json`。これは作品資料の事実を保存した手動レビューの記録で、収集CLIの候補レポートや取込用承認配列とは異なる。候補レポートのstatus=okやページハッシュを捏造して取込することはしない。レビュー済み作品を目次データに追加し、PRで検証する従来の手動登録経路を使用した。
