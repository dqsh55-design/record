# RECORD v0.69: representative edition selection

## Behavior

The main card is selected from retrieved eligible editions using a descending lexicographic tuple: official visibility, a usable registered label, registered front artwork (true above unknown above false/recent image failure), catalog number, valid-looking release date, registered track count. Ties preserve retrieval order. Only the selected edition is moved to the front; alternatives keep retrieval order. There are no artist, title, label-name allowlists or release-year preferences.

This is a metadata completeness choice, not independent official-release verification, an original-edition claim, sound-quality advice or streaming availability. The card still shows its own label, cover, edition date, evidence and saved links. The work's first-release date is unchanged. No label or image is copied from another edition. A CAA front=true registration does not guarantee a successful image download. A recent failed download is considered on the next rendering, without starting background image probes.

While any work detail is open or focus is inside a work, its existing main card is pinned. Incremental fetching cannot move an input into a closed disclosure. Pinning ends after the interaction closes and focus leaves the work, on a later rendering. An excluded/filtered-out pinned edition is not retained.

## Validation

Local Python matching 32 tests and all five Node suites pass. New pure selection cases cover incomplete status/label/art, registered art, failed art, interaction pinning, unchanged input order and no independent-verification promotion. Real previously captured Norah Jones editions now choose an Official, labeled, front-art-registered edition rather than the incomplete first record; captured Miles Davis and Jeff Beck details also beat incomplete synthetic counterparts. These are offline replay tests, not fresh external audits.

A new 320/390/430px browser case checks the displayed edition ID, label/date/evidence isolation, open details, URL draft/focus pinning when a richer edition arrives, preservation of all alternatives and no horizontal overflow. Existing browser tests are run through PR CI. Local browser installation remains unavailable due to failed Chromium downloads.

## Limits

Selection is confined to retrieved editions and available metadata, and can change when more complete information arrives outside an active interaction. Actual CAA image delivery, iPhone Safari and YouTube Music playback remain unverified. No additional MusicBrainz calls or image probes are introduced. PR submission does not publish v0.69.
