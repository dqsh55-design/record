# RECORD v0.72: edition evidence conflicts

An exact, reviewed negative edition reference now yields conflict/unknown even when no positive reference exists. Previously it needed a simultaneous positive reference, so MusicBrainz's Official status could leave the edition in the official category. Existing explicit Bootleg/Promotion/Pseudo-Release exclusions remain excluded. The finding is not automatically treated as a bootleg, and work-level confirmation remains independent. Conflict details retain the source link, including negative-only sources, so the reason can be inspected.

Exact matching now rejects impossible or partial edition dates and placeholder catalog numbers. A valid future release date remains eligible for an announced product; the independent review date must still be in the past. Dates are never rewritten. No production references, release classifications or streaming URLs were added.

Validation: Python matching 32 tests and all six Node suites pass locally, plus Python syntax and diff checks. New classifier cases cover negative-only evidence, invalid review dates, edition/artist identity isolation, impossible/partial release dates, future announcements and placeholder catalogs. The negative findings are synthetic test inputs, not new claims about the real artists. Existing recorded Miles Davis, Jeff Beck, Norah Jones and manually transcribed Healey Band work cases remain covered. A new browser test checks conflict source links, work/edition separation, URL draft/focus preservation and 320/390/430px layout; the full browser suite runs in PR CI.

Limits: independent references still cover only the previously reviewed small set. No new live API audit, iPhone Safari, playback authorization or live artwork delivery was tested. This PR does not publish the site.
